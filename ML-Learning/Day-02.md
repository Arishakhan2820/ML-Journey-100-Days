2. What is Artificial Intelligence (AI)?Definition: AI is the broad concept of making machines or software mimic human intelligence—enabling them to think, make decisions, and perform tasks like humans.History & Symbolic AI: Research on AI has been going on for 40–50 years. In the early days, Symbolic AI (Expert Systems) were used. Experts manually fed rules in the form of if-else statements into a code base (like chess-playing programs or medical expert systems).The Limitation of Early AI: These systems were restricted to narrow, fixed problems. If given a slightly complex task (like recognizing a dog in an image), Symbolic AI completely failed because you cannot manually code rules for every single breed and variation. This failure led to the birth of Machine Learning.3. What is Machine Learning (ML)?Definition: Machine Learning is a sub-field of AI where you do not write explicit rules (code).How it Works: * You feed Data + Answers (e.g., photos and their labels) into the system.The algorithm analyzes mathematical patterns in the data and automatically generates the rules through a process called Training (or Learning).Example: Instead of writing rules for what a dog looks like, you show the model thousands of pictures of dogs and non-dogs. The model automatically learns the underlying visual patterns to classify future images.4. What is Deep Learning (DL) & Why Do We Need It?If Machine Learning was already so good, why did we need Deep Learning? Let's break down the reasons:A. Feature EngineeringIn Machine Learning: You have to manually create and define the features (e.g., if predicting student placements, you must manually give features like CGPA, marks, and skills).In Deep Learning: You don't need to manually engineer features. Deep learning models automatically extract features from raw data, which is crucial for complex tasks like image, speech, and video recognition.B. Inspired by Neural NetworksDeep Learning is based on Artificial Neural Networks (ANN), which are loosely inspired by biological neurons in the human brain.As you stack more layers into a neural network, the model's depth increases. The early layers catch simple things (like edges), the middle layers catch shapes, and the deeper layers recognize the entire object.5. Data vs. Performance Graph (ML vs. DL)Machine Learning: Performs exceptionally well with small or medium amounts of data. However, after a certain point, throwing more data at an ML model causes its performance to plateau (stop improving).Deep Learning: Is data-hungry! The more data you feed a deep learning model, the more exponentially its performance improves.6. When to Use What?
